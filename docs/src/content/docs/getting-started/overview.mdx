PowerSchool Starter is a starting point for multi-tenant web applications that integrate with PowerSchool. It is built by [Archboard](https://archboard.io) and the source is on [GitHub](https://github.com/archboard/laravel-powerschool-starter). Replace this page with an overview of the app you build on it.

## Who uses it

| Role | What they do |
| --- | --- |
| District admin | Connects PowerSchool, chooses the active schools, configures email, and manages users and permissions across the district. |
| School staff | Work within their school, with permissions granted per school. |
| Guardian | Signs in with PowerSchool and sees their linked students. |

## Features

- **PowerSchool integration.** Install the plugin and schools, sections, students, teachers and contacts sync automatically, with single sign-on for everyone.
- **Multitenancy.** Each district is a tenant, self-hosted or in the cloud.
- **Multilingual.** The interface is available in English, Chinese, Korean, Japanese, Spanish and Arabic.
- **Activity log.** A record of changes to settings and synced records.
